What Handshake does

Handshake is a peer-to-peer, non-custodial escrow contract on chain 1404. Anyone can lock up BDAG or any ERC-20 token and post it as an open offer; a counterparty fills it and both assets change hands in one atomic transaction — either the full trade settles, or nothing moves at all. There's no pooled liquidity, no order book matching engine, and no intermediary ever holding funds — the contract itself is the only escrow.

TWO-WAY OFFERS
Give BDAG for a token, or give a token for BDAG — either direction, same contract.
PRIVATE OR OPEN
Restrict a deal to one specific wallet, or leave it open for anyone to fill.
CANCEL ANYTIME
Makers can pull an open offer back before it's filled — no lockup beyond that.

FAQ

No — escrow doesn't require a matching currency on both sides. Every offer here already pairs two different assets: BDAG on one side and any ERC-20 token on the other. Just like modern cross-border escrow isn't limited to a single currency, this contract locks one asset and releases it only when the counter-asset is delivered — atomically, in the same transaction — so mismatched pairs settle just as safely as identical ones.
Handshake doesn't vet, allowlist, or restrict which ERC-20 contracts it accepts — it locks and releases whatever token address you or a counterparty enters. That flexibility cuts both ways: a non-standard or deliberately malicious token contract could report a successful transfer without behaving the way a normal token would. The live check under the token address field confirms a contract exists and returns a symbol/decimals — it does not confirm the token is trustworthy. Only trade tokens you've independently verified yourself.
